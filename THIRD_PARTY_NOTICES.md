# Third-party notices and code reuse

This file tracks third-party code included in MinecraftShadersByAI.

## Reuse policy

We may reuse code from verified CC0-licensed shader repositories. Although CC0 generally does not require attribution, we will credit upstream authors as a matter of project policy. For every reused or adapted snippet, record:
- Upstream project and author
- Exact source URL and commit/tag when possible
- Licence and a link to the licence text
- Files or functions reused
- Changes made and where the adapted code now lives

**Do not copy code merely because a repository says it is open source.** Check the actual licence and whether it covers the specific file. If a source has no clear licence, or has restrictions incompatible with this project, do not copy its code. Inspiration from a technique is different from copying implementation.

## Third-party code currently included

No third-party shader code has been intentionally imported yet. The current shader files are initial project prototypes; this section must be updated before any external code is added.
